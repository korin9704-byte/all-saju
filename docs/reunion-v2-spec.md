# 재회 사주 v2 — 고정 목차 개편 명세

경쟁사(청월당 "홍연아씨 재회비책") 결과지 전문 분석 기반. 2026-09-15.
구성·정보 항목만 참고, 제목·문장·캐릭터는 냥점(묘묘) 것으로 새로 작성.

## 경쟁사 구성 요약 (참고용)

- 화자: 캐릭터 "홍연"이 반말로 이름을 부르며 진행 ("재영아, 왔어?")
- 페이지 단위 결과지 (?page=N), 각 장 = 대화 연출 + 위젯 + 본문 카드 2~4개
- 본문 소제목당 600~900자, 사주 근거(일간·십성·충파·신살)를 일상어로 풀고 생활 예시 필수
- 점수 위젯 다수: 재회 가능성 41점(프롤로그·7장), 상대 재회욕구 50점(3·4장), 재회 후 40점(5장), 새 연애 64점(6장)
- 1장에 명식표 풀세트 2개(나+상대): 십성/십이운성/신살/귀인 + 오행분포·비율(%·발달/적정/과다/결핍) + 용신·희신·기신 + 신강신약 스케일
- 4장 캘린더: 향후 3개월 달력 + 골든타임 날짜 3개(각 확률%와 사주 이유)
- 3장 "연적", 6장 "새 인연"은 외모(키·머리)·직업 분야·만나는 장소까지 구체 묘사
- 7장 마지막 편지 + 부적 다운로드 선물 + 만족도 설문

## 냥점 버전 목차 (화자: 묘묘)

| # | 장 제목 | 콘텐츠 |
|---|---|---|
| 0 | 프롤로그. 묘묘의 인사 | 이름 부르는 인사 대화 → **재회 가능성 N점 게이지** + 서브 게이지 3종(상대의 재회 마음/두 사람의 합/다시 만난 뒤의 합) → 목차 티저 |
| 1 | 1장. 우리는 어떤 두 사람이었을까 | 내 명식표+오행·용신·신강약 → "나는 어떤 사람"(타고난 성향/연애 스타일·애착) → 상대 명식표+오행 → "그 사람은 어떤 사람" → "우리 궁합과 지나온 연애" |
| 2 | 2장. 이별의 진짜 이유 | 연애 중 갈등의 뿌리 → 이별의 진짜 원인 → 이별 때 나도 몰랐던 내 마음 → 이별 전·직후 상대의 마음 |
| 3 | 3장. 지금, 그 사람의 마음 | 상대의 현재 상황 → ⚠️연적 경고(유형·장소) → **상대 재회 마음 N점** → 재회에 대한 상대 생각 → 망설이는 이유 |
| 4 | 4장. 다시 이어지는 시기 | **3개월 캘린더 + 골든타임 날짜 3개(확률%+이유)** → 접근 전략(연락 수단/차단 시/멘트 예시) → 마인드셋 → 장소 → 행운 아이템(패션·향) → 하지 말아야 할 행동 |
| 5 | 5장. 다시 만난다면 | **재회 후 관계 N점** → 재회 후 흐름 → 조심할 시기·사건 → 결혼 가능성 → 잘 지내는 법 → 갈등 대처 |
| 6 | 6장. 만약 놓아준다면 | 새 인연 프로필(분위기·만나는 곳) → 다음 연애 시기(연·월) → 다가가는 법 → **새 연애 가능성 N점** → 재회 vs 새 인연 비교 + 묘묘의 추천 |
| 7 | 7장. 묘묘의 마지막 편지 | 총평(점수 재확인+시나리오) → 새 인연의 희망 → 응원 편지 → 🎁 행운 부적 다운로드 |

## 톤 규칙

- 묘묘가 반말로 이름 부름 ("○○아/야"). 공감 먼저, 판정은 직설, 마무리는 위로
- 모든 판단에 사주 근거(일간 오행 비유·십성·충/파·신살)를 일상어로 + 생활 밀착 예시 1개 이상
- 상대방 미입력 시: 명식표·궁합 섹션은 내 사주 기준 서술로 대체, 단정 금지

## 점수 산출 (LLM이 아닌 코드에서 일관 계산 권장)

- 재회 가능성(0~100), 상대 재회 마음, 재회 후 관계, 새 연애 가능성 — 프롬프트에 값 주입해 본문과 일치시킴

## 구현 범위

1. 프롬프트: 장별 고정 구조 + 섹션별 브리프(JSON 출력) — 기존 자유 13주제 대체
2. 뷰어: 재회 전용 북 페이로드 빌더 (기존 lifebook 뷰어 카드 재활용: 명식표·게이지 바·캘린더)
3. 점수 계산 로직 + 캘린더 날짜 선정(운 흐름 기반)
4. 부적 이미지 1종 (묘묘 스타일) + 다운로드 카드
